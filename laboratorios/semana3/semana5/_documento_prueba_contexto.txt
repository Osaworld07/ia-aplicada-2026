Parte 1 — Tokens: la unidad con la que el modelo lee
Un modelo de lenguaje no lee letras ni palabras: lee tokens, fragmentos de texto que el modelo aprendió a reconocer durante su entrenamiento. Todo límite de un modelo (cuánto puede leer, cuánto cuesta, cuánto puede responder) se mide en tokens.


Paso 1.1 — Tokeniza una frase sencilla


Abre el tokenizador web. Escribe esta frase exactamente:


La inteligencia artificial aplicada resuelve problemas reales.


Observa dos números: la cantidad de caracteres y la cantidad de tokens. Observa también cómo el tokenizador colorea cada fragmento: verás que algunas palabras son un solo token y otras se parten en dos o tres.


Anota en tu reporte: número de caracteres, número de tokens y qué palabras se partieron.


Si falla: si el tokenizador muestra un selector de modelo, elige el más reciente disponible. Si la página no carga, usa la alternativa indicada en Requisitos; los números variarán un poco entre tokenizadores, y eso también es una observación válida.


Captura obligatoria: tokenizador mostrando la frase coloreada por tokens con el conteo visible.

Parte 2 — Temperatura: por qué el modelo no siempre responde igual
Al generar cada token, el modelo calcula una probabilidad para cada token posible y elige uno. La temperatura controla cuánto se permite elegir tokens poco probables. Con temperatura 0 tiende a elegir siempre el más probable; con temperatura alta explora opciones menos probables y las respuestas varían más.


Paso 2.1 — Abre Google AI Studio y localiza el control de temperatura


Entra a https://aistudio.google.com con tu cuenta de Google. Crea un nuevo prompt de tipo chat. En el panel lateral de configuración del modelo busca el control llamado "Temperature" o "Temperatura". Verás un deslizador o un campo numérico. Anota el rango que permite (normalmente de 0 a 2) y el valor por defecto.


Si falla: si no ves el panel de configuración, busca un ícono de ajustes o de deslizadores en la parte superior derecha. Si tu cuenta no tiene acceso a AI Studio en tu región, usa la alternativa del Paso 2.4.


Captura obligatoria: AI Studio con el panel de configuración abierto y el control de temperatura visible.

Parte 3 — Ventana de contexto: cuánto puede recordar el modelo
La ventana de contexto es la cantidad máxima de tokens que el modelo puede recibir y producir en una sola interacción. Todo lo que quede fuera de esa ventana no existe para el modelo. Y aun dentro de ella, la información situada en medio de un texto largo suele recuperarse peor que la del inicio o el final.


Paso 3.1 — Prepara la aguja y el pajar


Vas a esconder un dato ficticio en tu documento largo y comprobar si el modelo lo encuentra. Abre el documento de cuatro páginas en un editor de texto. Inserta esta frase exactamente a la mitad del documento, en medio de un párrafo, sin resaltarla:


El código de verificación interno de este documento es AZUL-7342.


Guarda el documento como documento_prueba_contexto.txt. Anota en qué página y párrafo quedó la frase.


Paso 3.2 — Pregunta por la aguja con el documento completo


En AI Studio (o en ChatGPT/Gemini) abre un chat nuevo. Pega el documento completo seguido de esta pregunta:


Con base únicamente en el texto anterior, ¿cuál es el código de verificación interno del documento? Si no aparece, responde "No aparece".


Anota si el modelo respondió AZUL-7342, si respondió "No aparece" o si inventó otro código. Registra también cuántos tokens mostró la interfaz para el chat, si el dato es visible (AI Studio muestra el conteo de tokens del contexto).


Si falla: si la interfaz rechaza el texto por ser demasiado largo, ese rechazo es un resultado: anótalo con el número de tokens estimado en el Paso 1.3 y reduce el documento a la mitad para continuar.


Captura obligatoria: respuesta del modelo a la pregunta del código con el conteo de tokens visible si la interfaz lo muestra.
